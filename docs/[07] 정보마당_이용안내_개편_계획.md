# [07] 정보 마당 · 이용 안내 개편 계획

> 작성일: 2026-10-22 · 브랜치 기준: `dev` · 개정 3 (구현 완료 기준)

## 확정된 결정

| 항목 | 결정 |
| --- | --- |
| A 페이지 이름 | **이용 안내** |
| A 페이지 주소 | **`/help`** (기존 `/guide`는 `/help`로 리다이렉트) |
| 뉴스 | **정보 마당 "다시 만난 이야기" 탭에 전체 목록**, **마이페이지에는 3건 요약** + "자세히 보기" → `/community?tab=news` |
| 캠페인 | **이번 범위에서 제외** (캠페인 사례 데이터·UI 삭제. 필요하면 git 기록에서 복구) |
| 전화 팝업 | 걸 수 있는 공식 번호를 **최대한** 제공 (112 · 182 · 실종아동전문기관 02-777-0182) |
| 메인 진입 | 실종아동 찾기가 메인 기능. 서비스 소개(`/about`)는 `/search`로 리다이렉트 |
| 로고 | 로그인 여부와 관계없이 **랜딩(`/`)** |

> 아래 본문 중 "캠페인 사례" 탭, `/community?tab=campaigns` 관련 내용은 위 결정으로 구현하지 않았다.
> 상황별 바로가기 3개는 `GuideSteps`의 상황 카드(`#know`, `#me`)와 겹쳐서 옮기지 않았다.

## 목표

1. **정보 마당**은 "읽을거리"만 모은다 → 소식·이야기(게시판) + 다시 만난 이야기(뉴스) + 캠페인 사례
2. **서비스 소개(`/about`) 자리**에 **이용 안내(`/help`)** 를 두고, 제보·상담 안내와 AI 연구 안내, 공식 기관 정보를 이쪽으로 옮긴다
3. `/about`의 소개 문구는 정리하고 **필요한 정보만** 이용 안내로 옮긴다. 기존 `/about` 주소로 들어오면 실종아동 찾기로 보낸다
4. 헤더의 **공식 제보 버튼**을 마이페이지 버튼과 같은 36×36 아이콘 버튼으로 통일하고, 누르면 **전화 선택 팝업**을 띄운다

```
헤더:  [FindUs → /]   실종아동 찾기 · 정보 마당 · 이용 안내 · 후원하기   [📞] [👤]

정보 마당 /community
 ├─ 소식·이야기      (기존 게시판 그대로)            /community
 ├─ 다시 만난 이야기  (뉴스 전체 목록)                /community?tab=news
 └─ 캠페인 사례      (캠페인 전체 목록)              /community?tab=campaigns

마이페이지 /mypage · 관심 아동 탭
 └─ 뉴스·캠페인 요약 (각 최신 3건) → [자세히 보기] → 정보 마당 해당 탭
```

## 작업 단계

### 1단계 — 뉴스·캠페인 데이터 분리

- `components/ReunionStory.tsx`의 `NEWS`, `CAMPAIGNS` 배열과 `Story` 타입을 `lib/reunionStories.ts`로 옮긴다.
- 전체 목록 UI는 `components/StoryLinkList.tsx`(가칭)로 만든다: 종류 배지, 제목, 출처, 날짜, "새 창" 표시. 기존 ReunionStory 모달 안의 목록 마크업을 기반으로 한다.

### 2단계 — 정보 마당 탭 재구성

- `CommunityTabs`의 탭을 `소식·이야기 / 다시 만난 이야기 / 캠페인 사례`로 바꾸고 props도 `stories / news / campaigns`로 변경.
- `app/community/page.tsx`에서 `GuideContent`, `AiContent` import 제거, 새 목록 컴포넌트 연결.
- 탭 진입 주소: `?tab=news`, `?tab=campaigns` (마이페이지 `?tab=`과 같은 방식). 기존 `#ai` 해시 처리는 제거.
- 탭을 바꾸면 `router.replace`로 주소의 `tab`도 갱신해 새로고침·공유 시 같은 탭이 열리게 한다.
- 헤더 설명 문구 수정: "찾기에 필요한 안내부터…" → 이야기·소식 중심 문구로.

### 3단계 — 마이페이지 요약 + 자세히 보기

- `ReunionStory.tsx`는 **요약 전용**으로 바꾼다.
  - 데이터는 `lib/reunionStories.ts`에서 가져와 그룹별 최신 3건만 표시 (현재 레이아웃 유지).
  - 기존 "더보기" 모달 버튼 → **"자세히 보기" 링크**로 교체: 뉴스는 `/community?tab=news`, 캠페인은 `/community?tab=campaigns`.
  - 모달 관련 코드(`selected` 상태, `Modal`)는 제거.
- 위치는 그대로 관심 아동 탭 하단.

### 4단계 — 이용 안내(`/help`) 페이지 만들기

- `app/help/page.tsx` 새로 만들기, 제목/메타: "이용 안내", canonical `/help`.
- `components/HelpTabs.tsx`(가칭): `CommunityTabs`와 같은 접근성 패턴(role=tablist, 방향키 이동), `?tab=ai`, `?tab=info` 지원.
  - 탭 1 **제보·상담 안내**(기본): 상단에 `/about`의 상황별 바로가기 3개(이 사람을 알아요 / 혹시 나? / 가족·보호자 안내)를 같은 페이지 앵커(`#know`, `#me`, `#families`)로 → 아래 `GuideContent embedded`
  - 탭 2 **AI 연구 안내**: `AiContent embedded` + `/about`의 "AI 예상 모습은 준비 중" 안내
  - 탭 3 **공식 기관·서비스 정보**: `ServiceInfoContent` (안전Dream, 실종아동전문기관, 전화번호, 출처·저작권)
- `/about`에서 버리는 것: 히어로 문구, "주요 기능" 3카드 (랜딩·찾기 화면과 중복).

### 5단계 — 라우트 정리 및 리다이렉트

- `next.config.ts`에 리다이렉트 추가 (처음에는 `permanent: false`):
  - `/about` → `/search`
  - `/guide` → `/help` (브라우저가 `#know` 같은 해시는 리다이렉트 후에도 유지)
  - `/ai` → `/help?tab=ai`
- `app/about/`, `app/guide/`, `app/ai/` 삭제. `AboutPage.module.css`에서 바로가기 스타일이 필요하면 `HelpTabs` 쪽으로 옮긴다.
- 내부 링크 수정:
  - `/guide#…` → `/help#…`: `PublicSearchExplorer.tsx`(제보 배너) 등
  - `Header.tsx`: 비로그인 로고 링크 `/about` → `/`, `hideUtilityBar` 조건의 `/about` → `/help`
  - `Footer.tsx` 로고 링크 `/about` → `/`
  - `funding/FundingDetail.tsx`, `funding/FundingList.tsx`의 "FindUs 소개" → `/`
  - `RoutePalette.tsx`의 `/about` → `/help`
- 메뉴 수정:
  - `HeaderNav.tsx` `NAV_ITEMS`: `{ href: "/help", label: "이용 안내", short: "안내" }`. `/community` 활성 판정에서 `/guide`, `/ai` 제거
  - `HeaderNav.tsx` 햄버거 메뉴의 "서비스 정보" 버튼 제거 (이용 안내 탭 3으로 대체). 쓰는 곳이 없어지면 `ServiceInfoModal.tsx` 삭제
  - `MobileBottomNav.tsx` 전체 메뉴: "실종아동 찾기"를 맨 위에 강조, "이용 안내" 아래에 하위 항목(제보·상담 안내 `/help`, AI 연구 안내 `/help?tab=ai`) 배치, "서비스 소개·정보" 제거. `infoActive`에서 `/guide`, `/ai` 제거, 전체 메뉴 버튼 활성 조건 `/about` → `/help`

### 6단계 — 실종아동 찾기를 메인급으로

- `/about` 리다이렉트 대상을 `/search`로 (5단계).
- 헤더 내비 첫 항목 "실종아동 찾기" 유지, 모바일 하단 메뉴 첫 칸 유지.
- 랜딩(`/`, `HomeLanding`)의 첫 버튼(CTA)이 `/search`로 가는지 확인하고, 아니면 "실종아동 찾아보기"를 가장 눈에 띄는 버튼으로.
- (확인 필요) FindUs 로고를 `/search`로 바꿀지는 아래 "남은 확인 사항" 참고.

### 7단계 — 공식 제보 버튼 → 아이콘 + 전화 선택 팝업

- `components/ReportCallButton.tsx`(가칭, client)
  - 버튼: `HeaderActions.module.css`의 `boxedAction` + 새 `.call` 클래스 (`.account`와 같은 36×36, 같은 radius·테두리 톤). `PhoneIcon` 20px, `aria-label="공식 제보·신고 전화"`, `aria-haspopup="dialog"`.
  - 클릭 시 기존 `Modal` 사용, 제목 "공식 제보·신고 전화"
- 팝업 내용 (각 항목은 큰 터치 영역의 `tel:` 링크, 번호를 크게 표시):

  | 번호 | 라벨 | 설명 |
  | --- | --- | --- |
  | **112** | 긴급 신고 | 지금 눈앞에 있거나 위험한 상황일 때 |
  | **182** | 실종아동 제보·상담 | 경찰청 실종아동찾기센터. 목격 제보, 장기 실종 상담 |
  | **02-777-0182** | 실종아동전문기관 상담 | 가족 찾기, 유전자 검사, 장기 실종 가족 지원 상담 |

  - 하단 보조 링크: "온라인 제보: 경찰청 안전Dream ↗" (`SAFE182_URL`), "실종아동전문기관 ↗" (`MISSING_CHILD_CENTER_URL`), "자세한 제보 방법 → 이용 안내" (`/help`)
  - 데스크톱은 `tel:`이 동작하지 않을 수 있으므로 번호를 크게 보여주어 직접 걸 수 있게 한다.
  - ⚠️ 실종아동전문기관 번호(02-777-0182)는 구현 전에 공식 사이트에서 다시 확인한다.
- 전화 목록은 `lib/links.ts`에 `OFFICIAL_CALLS` 상수로 두고 `ServiceInfoContent`, `Footer`, `FundingStory`, 팝업이 같은 데이터를 쓰게 한다.
- `Header.tsx`의 기존 `<a href="tel:182">` 알약 버튼을 이 컴포넌트로 교체. 모바일/데스크톱 모두 아이콘 하나로 일관되게.
